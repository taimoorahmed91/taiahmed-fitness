Overview

What FitTrack Is

One personal tracker, split into eight areas that cover the full loop: get access, see today's status, log what you eat and do, and look back on your progress.

React + Vite + Supabase

A single-user-per-login web app; every area reads and writes to the same Supabase project.

Owner-approved access

New sign-ins wait for an owner to approve the profile before anything else unlocks.

Your data, exportable

CSV or a full JSON backup is one click away from the top navigation bar, any time.

Why It Matters

Setup Order Matters

Personal Data isn't just a profile form — the min/max ranges you set there are what every other screen measures against. Skip it, and the Dashboard and Meals have nothing real to compare you to.

1

Personal Data

Calorie, protein, and carb targets saved as a min and a max — not one fixed number.

2

targets.ts

Resolves the effective range for today — workout day vs. rest day, plus any extra activity.

3

Dashboard & Meals

Progress bars and “calories remaining” read straight off that resolved range.

Getting Started · Sign-in & Approval

Sign-in & Approval

Google sign-in, then an owner has to approve your profile before the app unlocks. //pending-approval/admin/approval

How to Use It
  1. 1On the Welcome screen, select Sign in with Google.
  2. 2Not approved yet? You land on “Please wait to be allowed” — use Sign Out if you picked the wrong account.
  3. 3An owner opens User Approval (owner-only nav item) and selects Approve next to your name.
  4. 4Reload the app — you're now on the Dashboard.
Advantages
  • One-click Google sign-in, no separate password to manage.
  • Owner-gated approval keeps the tracker private to intended users.
  • A separate OAuth consent screen supports external integrations without sharing credentials.

Calorie History

A day-by-day table of calories, protein, and carbs against your target range.

Daily Logging · Gym & Workout Templates /gym

Gym & Workout Templates

Templates do the setup once; a session just walks through them.

How to Use It
  1. 1On Gym, create a template: Template Name + an exercise list.
  2. 2Select a template to start a session from it.
  3. 3Log sets, reps, and weight per exercise as you go.
  4. 4Pause instead of quitting if interrupted — resume later from the same template.
  5. 5Finish the session when done.
Advantages
  • Build the template once, reuse it every session — no retyping exercise lists.
  • Pause/resume means an interrupted workout isn't lost.
  • Workout duration feeds the Training & Activity trend on Reports.

A personal audit trail for everyone, plus a sign-up queue for owners only.

How to Use It
  1. 1Open Audit Log from the nav to see your own recent actions, searchable and filterable by category and status.
  2. 2Expand an entry to see its recorded details.
  3. 3Owners only: open User Approval to review pending sign-ups (with wait time) and select Approve.
Advantages
  • A factual trace of what changed and when — useful for spotting an accidental delete or duplicate entry.
  • Category and status filters make a specific event easy to find in a long history.
  • The approval queue shows how long each sign-up has waited, so the owner can prioritize at a glance.
