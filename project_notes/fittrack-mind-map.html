Cross-Domain Data Flows

  • WHOOP sync function feeds Health & Recovery and Daily Dashboard recovery/strain metrics. sync-whoop-data → useWhoopData → Dashboard, WhoopData
  • Settings, workout-day status, and extra activity establish calorie targets; meal entries show progress against them. useUserSettings + useGymSessions + useExtraActivities → targets.ts → Dashboard, Reports
  • Approval status from User Access gates every authenticated route rendered by the app shell. UserContext → App.tsx route guards → all pages
  • Daily notes remain date-linked records, while authenticated assistant requests travel through the chat webhook to n8n. useDailyNotes → DailyNotes | ChatBot → chat-webhook → n8n
  • Personal targets and protein settings influence dashboard calculations and nutrition progress views. usePersonalData + useUserSettings → targets.ts → Dashboard, Nutrition
  • All 50 migrations define the tables every hook in every branch reads/writes via the Supabase client. migrations/*.sql → client.ts → all hooks

Feature Guide: What It Does, How to Use It, and Why It Helps

Seventeen user-facing features, each read off the branches above. Every card states what the feature does, the concrete steps to use it, and the concrete advantages it gives — grounded in the pages, hooks, and functions that implement it.

Sign-in & Approval

What it does

New users sign in with a Google account; access is held at a waiting screen until an owner approves the profile.

How to use it
  1. On the welcome screen, select “Sign in with Google”.
  2. If not yet approved, you land on “Please wait to be allowed” (sign out from there if needed).
  3. An owner opens User Approval and selects Approve next to the pending name.
  4. Reload the app to reach the Dashboard once approved.
Advantages
  • One-click Google sign-in, no separate password to manage.
  • Owner-gated approval keeps the tracker private to intended users.
  • A separate OAuth consent screen supports connecting external integrations without sharing credentials.

src/pages/Welcome.tsx, PendingApproval.tsx, AdminApproval.tsx, OAuthConsent.tsx, src/contexts/UserContext.tsx

Dashboard

What it does

Shows today's status in one place: calories vs. target, yesterday's recap, and open goals, with a visible countdown to the daily reset.

How to use it
  1. Open Dashboard from the nav (the default landing page after sign-in).
  2. Review the stat cards and calorie goal progress bar for today.
  3. Check the Yesterday status and Goals card for anything still open.
Advantages
  • One screen for “where do I stand today” instead of checking each tracker separately.
  • Calorie/macro targets adjust automatically for workout vs. rest days.
  • Visible UTC reset countdown removes ambiguity about when a new day starts.

src/pages/Dashboard.tsx, src/components/StatsCards.tsx, CalorieGoalProgress.tsx, YesterdayStatus.tsx, GoalsCard.tsx, src/hooks/useDailySummary.ts

Meals & Nutrition

What it does

Logs individual meals with calories, protein, and carbs, and compares the day's intake against calorie and macro targets.

How to use it
  1. Open Meals from the nav.
  2. Fill in “What did you eat?”, calories, and optional protein/carbs, then submit.
  3. Use the list's edit, copy, or delete actions to adjust a logged meal.
  4. Check Calorie History for the full logged archive.
Advantages
  • Calorie and macro targets are computed automatically rather than entered by hand.
  • Meal-time distribution chart shows when calories are consumed, not just how many.
  • The copy action speeds up logging repeat meals.
  • Calorie History adds 7D/14D/30D/All quick filters and a Summary for Selected Days panel (avg calories, protein, carbs, target-range hit rate).

src/pages/Meals.tsx, CalorieHistory.tsx, src/components/MealForm.tsx, MealList.tsx, CalorieBalanceChart.tsx, MacroTargetChart.tsx, MealTimeChart.tsx, src/lib/targets.ts

Gym & Workout Templates

What it does

Runs and records gym sessions from reusable templates, tracking sets, reps, weight, and session duration per exercise.

How to use it
  1. Open Gym from the nav.
  2. Create a template (name + exercises) or pick an existing one.
  3. Select a template to start a workout; the active-session modal tracks sets as you go.
  4. Finish, or pause and resume later; edit a past session's notes if needed.
Advantages
  • Templates remove the need to retype the same exercise list every session.
  • Pause/resume support means an interrupted workout isn't lost.
  • Workout duration chart turns logged sessions into a visible training-volume trend.

src/pages/Gym.tsx, src/components/WorkoutTemplateForm.tsx, WorkoutTemplateList.tsx, ActiveWorkoutModal.tsx, EditTemplateModal.tsx, EditWorkoutSessionModal.tsx, WorkoutDurationChart.tsx, src/hooks/useGymSessions.ts, useWorkoutTemplates.ts

Extra Activities

What it does

Logs non-gym activity — walks, hikes, sports, chores — with optional duration and calories that count toward the day's calorie goal.

How to use it
  1. Open Extra Activity from the nav.
  2. Fill in the activity details and, optionally, duration, calories, and notes, then select “Add Activity”.
  3. Use the date range and search filters to find or edit a past entry.
Advantages
  • Captures calorie-relevant movement that gym logging alone would miss.
  • Extra calories feed directly into the same daily target used by Dashboard and Meals.
  • Searchable, date-filtered history makes a specific entry easy to find later.

src/pages/ExtraActivities.tsx, src/hooks/useExtraActivities.ts

Weight & Waist

What it does

Logs weight and waist measurements over time with notes, each on its own page with its own trend chart.

How to use it
  1. Open Weight or Waist from the nav.
  2. Enter the measurement and an optional note, then select “Add Entry”.
  3. Use search/sort to review history, or edit/delete an entry from its dialog.
  4. Optionally set a logging-interval reminder from Personal Data.
Advantages
  • Separate pages keep weight and waist overviews uncluttered from each other.
  • A shared overview card shows vs-previous, 7/15/30-day deltas, and progress toward a weight target or measuring cadence.
  • BMI on Personal Data is calculated automatically from the latest weight and stored height.

src/pages/Weight.tsx, Waist.tsx, src/components/MetricOverviewCard.tsx, WeightIntervalSetting.tsx, src/hooks/useWeight.ts, useWaist.ts, usePersonalData.ts, useUserSettings.ts

Sleep

What it does

Logs sleep duration and notes per day. The page shows a Sleep Overview (last night, 7-day and 30-entry averages, best/shortest night, optimal-range tally); Dashboard charts it alongside other health trends.

How to use it
  1. Open Sleep from the nav.
  2. Enter hours slept and an optional note, then select “Add Entry”.
  3. Use search and sort controls to review past entries, or edit one from its dialog.
Advantages
  • Dashboard and Calendar both surface sleep alongside the same day's meals and workouts.
  • Simple hours-plus-notes format keeps logging under a minute.

src/pages/Sleep.tsx, src/hooks/useSleep.ts

WHOOP Recovery

What it does

Pulls WHOOP recovery, strain, and sleep data in from a configured API URL and displays it as a recovery trend alongside manually tracked entries.

How to use it
  1. Open WHOOP Data from the nav.
  2. Expand the collapsible WHOOP API URL panel, paste the URL, and save it.
  3. Select the fetch/refresh action to pull in the latest entries.
  4. Edit or delete an individual entry if a value looks wrong.
Advantages
  • Wearable recovery and strain data supplements manually logged training and sleep.
  • A background sync function can keep entries current without a manual fetch every time.
  • Recovery chart feeds the same dashboard used for meals and training, giving one combined view.

src/pages/WhoopData.tsx, EditWhoopEntryDialog.tsx, src/hooks/useWhoopData.ts, supabase/functions/sync-whoop-data/index.ts

Calendar

What it does

Shows six month-summary tiles (meal days, workouts, weigh-ins, sleep logs, waist logs, notes) above a month grid where each day indicates which trackers have entries, filterable by type.

How to use it
  1. Open Calendar from the nav.
  2. Use the filter selector to show all entry types or narrow to one (e.g. gym only).
  3. Navigate between months with the arrow controls and select a day to see what was logged.
Advantages
  • Gives a quick visual read on logging consistency across every tracker at once.
  • Filtering by category makes it easy to audit one habit at a time.

src/pages/Calendar.tsx

Compare

What it does

Puts two dates side by side across meals, gym, weight, or sleep, including a set-by-set breakdown for gym sessions.

How to use it
  1. Open Compare from the nav.
  2. Pick a category — meals, gym, weight, or sleep — and the two dates to compare.
  3. For gym, review the exercise-by-exercise, set-by-set comparison parsed automatically from session notes.
Advantages
  • Directly answers “how does this compare to last time” without manually cross-referencing history pages.
  • Granular gym comparison shows progress per exercise, not just per session.

src/pages/Compare.tsx

Reports

What it does

Summarizes calorie, workout, sleep, and weight stats over the last 7 or 30 days, with correlation-style insights and a shareable summary image.

How to use it
  1. Open Reports from the nav.
  2. Switch between the “Last 7 Days” and “Last 30 Days” tabs.
  3. Review the stat cards, charts, and insight cards.
  4. Select Download or Share to export the summary as an image.
Advantages
  • Turns scattered daily logs into a single period-level summary.
  • Shareable image export makes it easy to send progress outside the app.
  • Correlation insights surface patterns a single chart wouldn't show.

src/pages/Reports.tsx, src/components/ReportCharts.tsx, InsightCard.tsx, ShareableSummary.tsx, src/hooks/useReportData.ts

Goals & Achievements

What it does

Tracks goal-hit streaks and awards badges for consistency across calories, workouts, and sleep.

How to use it
  1. Set targets via the Goals card on the Dashboard or via Personal Data targets.
  2. Open Achievements from the nav to see goals set, goals met, current streak, and longest streak.
  3. Review earned vs. not-yet-earned badges.
Advantages
  • Converts daily targets into a visible motivation signal instead of silent pass/fail.
  • Separate categories (calories, workouts, sleep) stop one metric from hiding progress in another.
  • A collection-progress bar shows how many badges have been earned overall, at a glance.

src/pages/Achievements.tsx, src/hooks/useGoalAchievements.ts, src/components/GoalsCard.tsx, src/hooks/useGoals.ts

Daily Notes

What it does

Logs free-text notes (with optional tags and a severity score) about symptoms, feelings, or events on a given date, separate from the quantitative trackers.

How to use it
  1. Open Daily Notes from the nav.
  2. Write a note in the form and submit it.
  3. Search, or filter by tag, to find a specific note fast.
  4. Edit or delete an existing note from the list.
Advantages
  • Captures context (illness, stress, travel) that explains anomalies in weight, sleep, or calorie charts.
  • Notes stay date-linked, so they line up with the corresponding entries on Calendar.
  • Summary tiles surface patterns — total notes, last 30 days, most common tag, and average severity.

src/pages/DailyNotes.tsx, src/components/DailyNoteForm.tsx, DailyNotesList.tsx, src/hooks/useDailyNotes.ts

Personal Data & Targets

What it does

Stores profile basics, nutrition and training targets as min/max ranges, a per-weekday workout-template schedule, rest timers, an API token, and a live BMI reading.

How to use it
  1. Open Personal Data from the nav.
  2. Fill in body/profile fields and nutrition target multipliers, min and max.
  3. Assign a workout template to specific weekdays under Training Schedule.
  4. Generate, refresh, or revoke the API token if external access is needed.
Advantages
  • Min/max ranges, not single numbers, drive the calorie and macro targets used throughout the app.
  • Per-weekday template assignment ties training schedule directly to Gym.
  • BMI is computed live from stored height and the latest logged weight.
  • The token is shown in plaintext only once at generation, reducing exposure risk.

src/pages/PersonalData.tsx, src/hooks/usePersonalData.ts, usePersonalDataHistory.ts, src/lib/targets.ts, supabase/functions/api-token/index.ts

Messaging & Assistant

What it does

Configures Telegram and email notifications on a schedule, shown as status-overview cards (Telegram, Email, Schedule), and provides an in-app chat assistant for quick data questions.

How to use it
  1. Open Messaging from the nav.
  2. Message the configured Telegram bot to get a chat ID, paste it in, and save.
  3. Toggle Telegram/email subscriptions and set a notification schedule.
  4. Use the chat bubble, available on any page, to ask quick questions by category.
Advantages
  • The notification schedule shows an actual cron expression, not a hidden black box.
  • The chat assistant is rate-limited, keeping it available without runaway usage.
  • Telegram and email channels can be toggled independently of each other.

src/pages/Messaging.tsx, src/components/NotificationScheduleForm.tsx, ChatBot.tsx, supabase/functions/chat-webhook/index.ts

Data Import/Export

What it does

Exports logged data as CSV (per category or all) or as a full/range JSON backup, and imports a previously exported JSON backup.

How to use it
  1. Open the export/import menu from the top navigation bar, available on every page.
  2. Choose CSV export for a single category or all data, or JSON export for a full/range backup.
  3. To restore, choose Import, select a previously exported JSON file, and confirm the import dialog.
Advantages
  • Available from every page, with no need to navigate to a specific settings screen first.
  • JSON backup/restore gives a path to move or recover data outside the live database.
  • CSV export supports pulling a single category, such as meals, into a spreadsheet.

src/components/ImportExportButton.tsx, src/lib/exportData.ts, jsonExportImport.ts

Activity Logs / Admin

What it does

Keeps a personal, filterable audit trail of actions across categories, and gives owners a User Approval queue — a two-column grid of pending sign-ups, each with an avatar initial and how long they've waited.

How to use it
  1. Open Audit Log from the nav to see recent actions, searchable and filterable by category and status.
  2. Expand an entry to see its recorded details.
  3. Owners only: open User Approval to review pending sign-ups (with wait time) and select Approve.
Advantages
  • Gives a factual trace of what changed and when, useful for spotting an accidental delete or duplicate entry.
  • Category and status filters make a specific event easy to find in a long history.
  • The approval queue shows how long each sign-up has waited, so the owner can prioritize at a glance.

src/pages/ActivityLogs.tsx, AdminApproval.tsx, src/hooks/useActivityLog.ts, src/contexts/UserContext.tsx
